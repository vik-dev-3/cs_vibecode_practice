# 0002. Postgres + pgvector для данных и векторов

- Статус: Принято
- Дата: 2026-10-30

## Контекст
Для RAG нужен поиск по эмбеддингам. При этом векторы надо фильтровать по рабочему пространству и правам — это реляционные данные.

## Решение
Одна база Postgres с расширением pgvector: и обычные таблицы, и векторы чанков.

## Альтернативы
- **Отдельная векторная БД (Pinecone, Qdrant, Weaviate)** — ещё один сервис, синхронизация двух хранилищ, права дублируются; оправдано на миллионах+ векторов.
- **SQLite / MongoDB** — нет того же уровня транзакций и экосистемы для продакшена на Railway.

## Последствия
+ Один источник правды: удалили документ — чанки удалились в той же транзакции.
+ Фильтр по `workspace_id` и поиск по вектору — в одном SQL-запросе.
− Масштаб ограничен одной базой; для учебного проекта с запасом.
