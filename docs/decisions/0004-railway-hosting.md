# 0004. Хостинг на Railway

- Статус: Принято
- Дата: 2026-10-30

## Контекст
Нужно хостить Next.js, долгоживущий воркер, Postgres с pgvector и Redis, с окружениями staging и production.

## Решение
Railway: все четыре сервиса в одном проекте, два окружения, деплой из GitHub.

## Альтернативы
- **Vercel** — лучший хостинг для Next.js, но serverless: долгоживущий воркер там не живёт, Postgres/Redis — через сторонних провайдеров.
- **Fly.io / Render** — похожие возможности; Railway проще в настройке окружений.
- **Свой VPS + Docker** — дешевле, но обновления, бэкапы и TLS на нас; отвлекает от целей проекта.

## Последствия
+ Всё в одном месте, окружения из коробки.
− Платный по использованию: обязателен лимит расходов.
− Vendor lock-in умеренный: всё стандартное (Docker, Postgres, Redis), переезд возможен.
